# Sales Performance Dashboard

## Overview

This project analyzes the Superstore Sales Dataset using Microsoft Excel to evaluate sales performance through KPI reporting, Pivot Tables, interactive dashboards, and Root Cause Analysis (RCA).

## Objectives

- Clean and prepare the dataset
- Build Pivot Tables and Pivot Charts
- Create an interactive dashboard
- Analyze YoY and QoQ trends
- Perform Root Cause Analysis

## Tools

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dataset

Superstore Sales Dataset (Kaggle)
